Unit 3Introduction to Hypothesis Testing

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

Hypothesis testing is the formal statistical procedure for deciding whether sample evidence is strong enough to challenge an existing claim about a population. This topic covers its vocabulary, logic, and the general step-by-step procedure used throughout this unit.

2. Detailed Notes

1.1 Meaning of Hypothesis Testing

Hypothesis testing is a statistical procedure that uses sample data to evaluate whether there is enough evidence to reject a stated claim (hypothesis) about a population parameter.

1.2 Null and Alternative Hypothesis

HypothesisMeaning
Null Hypothesis (H₀)The default claim of "no difference" or "no effect," assumed true unless the sample data provides strong evidence against it.
Alternative Hypothesis (H₁)The claim that contradicts the null hypothesis — what the test is trying to find evidence for.

A test is two-tailed when H₁ states the parameter is simply "not equal to" a value, and one-tailed when H₁ specifies a direction ("greater than" or "less than").

1.3 Type I and Type II Errors

H₀ is actually TrueH₀ is actually False
Reject H₀Type I Error (probability = α)Correct Decision
Fail to Reject H₀Correct DecisionType II Error (probability = β)
  • Type I Error: Rejecting a true null hypothesis (a "false positive"). Its probability is the significance level, α, commonly set at 0.05 or 0.01.
  • Type II Error: Failing to reject a false null hypothesis (a "false negative"). Its probability is denoted β.

1.4 Level of Significance and Critical Region

The level of significance (α) is the probability of making a Type I error that the researcher is willing to accept, typically chosen before the test is conducted. The critical region (or rejection region) is the range of test-statistic values for which H₀ is rejected; the critical value is the boundary of this region.

1.5 General Steps in Hypothesis Testing

  1. State the Null and Alternative Hypotheses (H₀ and H₁).
  2. Choose the Level of Significance (α), typically 0.05 or 0.01.
  3. Select the Appropriate Test Statistic (Z, t, F, or χ², depending on the situation).
  4. Determine the Critical Value(s) from the relevant statistical table.
  5. Calculate the Test Statistic from the sample data.
  6. Compare and Decide: If the calculated test statistic falls in the critical region (or if the p-value is less than α), reject H₀; otherwise, fail to reject H₀.
  7. State the Conclusion in the context of the original business or research question.

1.6 The p-Value Approach

The p-value is the probability of obtaining a test statistic at least as extreme as the one calculated, assuming H₀ is true. If the p-value is less than α, H₀ is rejected; this approach is equivalent to the critical-value approach but is more commonly reported by statistical software.

3. Key Terms

Null Hypothesis (H0)
The default claim of no difference or no effect, assumed true unless sample evidence strongly contradicts it.
Alternative Hypothesis (H1)
The claim that contradicts the null hypothesis, which the test seeks evidence for.
Type I Error
Rejecting a true null hypothesis; its probability is the significance level, alpha.
Type II Error
Failing to reject a false null hypothesis; its probability is denoted beta.
Level of Significance (alpha)
The probability of a Type I error that a researcher is willing to accept, commonly 0.05 or 0.01.
p-Value
The probability of obtaining a test statistic at least as extreme as the one observed, assuming the null hypothesis is true.

4. Exam-Prep Summary

  • H0 = default/no-difference claim; H1 = contradicting claim being tested for.
  • Type I error = reject true H0 (probability alpha); Type II error = fail to reject false H0 (probability beta).
  • 7 steps: State H0/H1 → Choose alpha → Select test statistic → Find critical value → Calculate test statistic → Compare & decide → Conclude.
  • p-value < alpha ⇒ reject H0 (p-value approach, equivalent to critical-value approach).

5. Practice Questions

  1. Define null and alternative hypothesis with an example.
    Show model answer
    The null hypothesis (H0) is the default claim of no difference, e.g. 'the mean delivery time is 30 minutes.' The alternative hypothesis (H1) is the contradicting claim being tested for, e.g. 'the mean delivery time is not 30 minutes.'
  2. Differentiate between Type I and Type II errors.
    Show model answer
    A Type I error is rejecting a true null hypothesis (a false positive), with probability alpha (the significance level). A Type II error is failing to reject a false null hypothesis (a false negative), with probability beta.
  3. Explain the general steps involved in hypothesis testing.
    Show model answer
    State H0 and H1, choose the significance level alpha, select the appropriate test statistic, determine the critical value from statistical tables, calculate the test statistic from sample data, compare the calculated value to the critical value (or the p-value to alpha) to decide whether to reject H0, and state the conclusion in context.
  4. What is a p-value? How is it used to make a decision?
    Show model answer
    The p-value is the probability of obtaining a test statistic at least as extreme as the one calculated, assuming the null hypothesis is true. If the p-value is less than the chosen significance level alpha, the null hypothesis is rejected; otherwise, it is not rejected.
