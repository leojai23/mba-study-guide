Unit 1Counting Rules, Sample Space and Events

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

Before probability can be calculated for complex situations, a few basic building blocks are needed: the language of experiments, sample spaces and events, and the counting rules used to work out how many outcomes are possible in the first place.

2. Detailed Notes

2.1 Basic Concepts

Experiment

A random experiment is any process that produces one of several possible outcomes, where the specific outcome cannot be predicted with certainty in advance (e.g. tossing a coin, rolling a die).

Sample Space

The sample space, denoted S, is the set of all possible outcomes of an experiment. For a single coin toss, S = {Head, Tail}.

Events

An event is any subset of the sample space — a collection of one or more outcomes that are of interest. A simple event consists of exactly one outcome; a compound event consists of two or more outcomes.

Union and Intersection of Two or More Events

  • Union (A ∪ B): The event that A occurs, or B occurs, or both occur.
  • Intersection (A ∩ B): The event that both A and B occur together.
  • Mutually Exclusive Events: Events that cannot occur at the same time, so A ∩ B = ∅ (the empty set).

2.2 Fundamental Rules of Counting

Counting rules determine how many total outcomes exist in situations too complex to list out by hand, which is essential for calculating classical probability.

The Multiplication Rule

If one task can be done in m ways and a second, independent task can be done in n ways, the two tasks together can be done in m × n ways.

2.3 Counting Rules for Permutations

A permutation is an arrangement of objects in a specific order, where order matters.

The number of permutations of n distinct objects taken r at a time is:

nPr = n! ÷ (n − r)!

where n! ("n factorial") = n × (n−1) × (n−2) × ... × 1.

2.4 Counting Rules for Combinations

A combination is a selection of objects where order does not matter.

The number of combinations of n distinct objects taken r at a time is:

nCr = n! ÷ [r! (n − r)!]

Combinations are always smaller than or equal to permutations for the same n and r, since combinations do not count different orderings of the same selection separately.

3. Key Terms

Random Experiment
A process that produces one of several possible outcomes, where the specific outcome cannot be predicted with certainty.
Sample Space (S)
The set of all possible outcomes of an experiment.
Event
Any subset of the sample space, representing one or more outcomes of interest.
Permutation (nPr)
An arrangement of n objects taken r at a time where order matters, calculated as n! / (n-r)!.
Combination (nCr)
A selection of n objects taken r at a time where order does not matter, calculated as n! / [r!(n-r)!].

4. Exam-Prep Summary

  • Sample space S = set of all possible outcomes; Event = subset of S (simple = 1 outcome, compound = 2+ outcomes).
  • Mutually exclusive events: A ∩ B = ∅ (cannot occur together).
  • Multiplication rule: m ways x n ways = m x n total ways.
  • Permutation (order matters): nPr = n! / (n-r)!
  • Combination (order doesn't matter): nCr = n! / [r!(n-r)!]

5. Practice Questions

  1. Define sample space and event, with an example.
    Show model answer
    The sample space is the set of all possible outcomes of an experiment (e.g. S = {Head, Tail} for a coin toss). An event is any subset of the sample space of interest, such as 'getting a Head', which here is a simple event since it contains one outcome.
  2. Differentiate between permutation and combination.
    Show model answer
    A permutation is an arrangement of objects where order matters, calculated as nPr = n!/(n-r)!. A combination is a selection of objects where order does not matter, calculated as nCr = n!/[r!(n-r)!]. For the same n and r, the number of combinations is always smaller than or equal to the number of permutations.
  3. Explain the multiplication rule of counting with an example.
    Show model answer
    If one task can be completed in m ways and a second independent task in n ways, the two tasks together can be completed in m x n ways. For example, if a restaurant offers 4 starters and 3 main courses, a diner can choose a starter-and-main combination in 4 x 3 = 12 ways.
  4. Calculate 5P2 and 5C2. Explain the difference in the results.
    Show model answer
    5P2 = 5!/(5-2)! = 5!/3! = 5 x 4 = 20. 5C2 = 5!/[2!(5-2)!] = (5 x 4)/(2 x 1) = 10. The permutation count is higher because it counts each pair of chosen items in both possible orders, while the combination count treats each pair as a single selection regardless of order.
