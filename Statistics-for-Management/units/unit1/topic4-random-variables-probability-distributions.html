Unit 1Random Variables and Probability Distributions

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

This topic bridges basic probability and probability distributions by introducing random variables — the way numerical outcomes are formally assigned to the results of a random experiment.

2. Detailed Notes

4.1 Random Variable — Concept

A random variable is a variable whose value is a numerical outcome of a random experiment. It assigns a real number to every possible outcome in the sample space.

4.2 Discrete Random Variables

A discrete random variable can take only a countable number of distinct values (e.g. the number of defective items in a batch of 10, which can only be 0, 1, 2, …, 10).

4.3 Continuous Random Variables

A continuous random variable can take any value within a given range (e.g. the exact weight of a product, or the time taken to complete a task), rather than being restricted to specific countable values.

4.4 Expected Value Concept

The expected value of a random variable is its long-run average value across many repetitions, calculated as:

E(X) = Σ [x × P(x)]

where the sum runs over every possible value x that the random variable X can take, weighted by its probability P(x). The expected value is also called the mean of the probability distribution, often denoted μ.

4.5 Probability Mass Function (PMF)

For a discrete random variable, the probability mass function gives the probability that the random variable takes each specific value: P(X = x). Every PMF must satisfy P(x) ≥ 0 for all x, and Σ P(x) = 1 across all possible values.

4.6 Probability Density Function (PDF)

For a continuous random variable, probability is described by a probability density function, where the probability of X falling within a given range is the area under the curve of the function over that range. Since a continuous variable has infinitely many possible values, the probability of it taking any single exact value is zero; only probabilities over an interval are meaningful.

4.7 Types of Probability Distribution

Probability distributions are classified as discrete (built from a PMF, e.g. Binomial and Poisson Distributions, covered in the next topic) or continuous (built from a PDF, e.g. the Normal Distribution, covered later in this unit).

3. Key Terms

Random Variable
A variable whose value is a numerical outcome of a random experiment, assigning a real number to every outcome in the sample space.
Discrete Random Variable
A random variable that can take only a countable number of distinct values.
Continuous Random Variable
A random variable that can take any value within a given range.
Expected Value E(X)
The long-run average value of a random variable, calculated as the sum of each value weighted by its probability.
Probability Mass Function (PMF)
A function giving the probability that a discrete random variable takes each specific value.
Probability Density Function (PDF)
A function describing the relative likelihood of a continuous random variable, where probability over a range equals the area under the curve.

4. Exam-Prep Summary

  • Random variable = numerical outcome of a random experiment; Discrete (countable values) vs Continuous (any value in a range).
  • Expected value E(X) = Sum of [x * P(x)] = mean of the probability distribution (mu).
  • PMF (discrete): P(X=x), with P(x) ≥ 0 and sum of all P(x) = 1.
  • PDF (continuous): probability over a range = area under the curve; probability of an exact single value = 0.
  • Discrete distributions: Binomial, Poisson; Continuous distribution: Normal.

5. Practice Questions

  1. Define random variable. Differentiate between discrete and continuous random variables.
    Show model answer
    A random variable is a variable whose value is a numerical outcome of a random experiment. A discrete random variable takes only a countable number of distinct values (e.g. number of defects), while a continuous random variable can take any value within a range (e.g. weight or time).
  2. What is the expected value of a random variable? Give its formula.
    Show model answer
    The expected value is the long-run average value of a random variable across many repetitions, calculated as E(X) = Sum of [x x P(x)] across all possible values x. It is also called the mean of the probability distribution.
  3. Differentiate between a probability mass function and a probability density function.
    Show model answer
    A probability mass function (PMF) applies to discrete random variables and gives the probability of each specific value, P(X=x). A probability density function (PDF) applies to continuous random variables, where the probability of X falling in a range is the area under the curve over that range, and the probability of any single exact value is zero.
