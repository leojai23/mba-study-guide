Unit 2Point and Interval Estimation for Large Samples

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

Estimation uses sample data to infer the value of an unknown population parameter. This topic covers point estimation, and interval estimation for large samples using the normal distribution.

2. Detailed Notes

4.1 Point Estimation

A point estimate is a single value, calculated from sample data, used as the best guess for an unknown population parameter. For example, the sample mean x̄ is the point estimate of the population mean μ, and the sample proportion p̅ is the point estimate of the population proportion p.

Properties of a Good Estimator

  • Unbiasedness: The expected value of the estimator equals the true population parameter.
  • Efficiency: Among unbiased estimators, the one with the smallest variance is preferred.
  • Consistency: As sample size increases, the estimator converges toward the true population value.

4.2 Interval Estimation (Confidence Intervals)

Because a point estimate alone gives no sense of its likely accuracy, an interval estimate (confidence interval) provides a range of values, together with a confidence level, within which the true population parameter is expected to lie.

4.3 Confidence Interval for the Population Mean (Large Sample, n ≥ 30)

x̄ ± Zα/2 × (σ ÷ √n)

where x̄ is the sample mean, Zα/2 is the Z-value corresponding to the desired confidence level (1.96 for 95% confidence, 2.58 for 99% confidence), σ is the population standard deviation (or the sample standard deviation s, if σ is unknown and n is large), and n is the sample size.

4.4 Confidence Interval for the Population Proportion (Large Sample)

p̅ ± Zα/2 × √[p̅(1−p̅) ÷ n]

where p̅ is the sample proportion.

4.5 Interpreting a Confidence Interval

A 95% confidence interval does not mean there is a 95% probability the true parameter lies in this specific interval. It means that if the same sampling procedure were repeated many times, approximately 95% of the resulting intervals would contain the true population parameter.

Factors Affecting Confidence Interval Width

  • A higher confidence level (e.g. 99% vs 95%) produces a wider interval.
  • A larger sample size produces a narrower interval, since the standard error decreases.
  • Greater variability in the data (larger σ) produces a wider interval.

3. Key Terms

Point Estimate
A single value calculated from sample data, used as the best guess for an unknown population parameter.
Interval Estimate (Confidence Interval)
A range of values, with an associated confidence level, within which a population parameter is expected to lie.
Confidence Level
The long-run proportion of repeated confidence intervals that would be expected to contain the true population parameter.
Unbiased Estimator
An estimator whose expected value equals the true population parameter being estimated.

4. Exam-Prep Summary

  • Point estimate = single best-guess value (e.g. x-bar estimates mu); properties of a good estimator: unbiasedness, efficiency, consistency.
  • CI for mean (large sample): x-bar +/- Z(alpha/2) x (sigma / sqrt(n)); common Z-values: 1.96 (95%), 2.58 (99%).
  • CI for proportion (large sample): p-hat +/- Z(alpha/2) x sqrt[p-hat(1-p-hat)/n].
  • Higher confidence level = wider interval; larger sample size = narrower interval; more variability = wider interval.

5. Practice Questions

  1. What is a point estimate? State the properties of a good estimator.
    Show model answer
    A point estimate is a single value from sample data used as the best guess for a population parameter, such as the sample mean estimating the population mean. A good estimator should be unbiased (expected value equals the true parameter), efficient (smallest variance among unbiased estimators), and consistent (converges to the true value as sample size grows).
  2. Write the formula for the confidence interval of the population mean for a large sample.
    Show model answer
    x-bar +/- Z(alpha/2) x (sigma / sqrt(n)), where x-bar is the sample mean, Z(alpha/2) is the Z-value for the desired confidence level, sigma is the population (or large-sample estimate of the) standard deviation, and n is the sample size.
  3. How does sample size and confidence level affect the width of a confidence interval?
    Show model answer
    A larger sample size narrows the confidence interval because the standard error decreases, giving a more precise estimate. A higher confidence level (e.g. 99% instead of 95%) widens the interval, since a wider range is needed to be more confident of capturing the true parameter.
