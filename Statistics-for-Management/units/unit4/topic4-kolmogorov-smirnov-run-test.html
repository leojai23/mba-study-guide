Unit 4Kolmogorov-Smirnov Test and One Sample Run Test

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

This topic covers two further non-parametric tests: the Kolmogorov-Smirnov test, which checks how well a sample fits a hypothesised distribution, and the One Sample Run Test, which checks whether a sequence of data is genuinely random.

2. Detailed Notes

4.1 Kolmogorov-Smirnov (K-S) Test — Purpose

The Kolmogorov-Smirnov test checks whether a sample's data is consistent with coming from a specific hypothesised distribution (a "goodness of fit" test), or whether two independent samples come from the same distribution (a two-sample version).

4.2 One-Sample K-S Test — Procedure

  1. State H₀: the sample comes from the specified theoretical distribution (e.g. normal).
  2. Calculate the sample's empirical cumulative distribution function (ECDF), the proportion of observations at or below each value.
  3. Calculate the theoretical cumulative distribution function (CDF) implied by the hypothesised distribution, at the same values.
  4. Find D, the maximum absolute difference between the empirical and theoretical CDFs across all observed values.
  5. Compare D against the critical D-value from K-S tables for the given sample size and significance level; if D exceeds the critical value, H₀ is rejected.

4.3 Comparing the K-S Test and the Chi-Square Goodness-of-Fit Test

Both tests assess how well data fits a hypothesised distribution, but the K-S test works directly with individual, ungrouped data values (comparing cumulative distributions), while the Chi-Square test (covered in the next topic) works with data grouped into categories or class intervals. The K-S test is often considered more powerful for continuous data, since it does not lose information through grouping.

4.4 One Sample Run Test — Purpose

The One Sample Run Test (Wald-Wolfowitz Runs Test) checks whether a sequence of binary outcomes (e.g. above/below the median, success/failure) occurs in a genuinely random order, rather than following a pattern.

4.5 Concept of a "Run"

A run is a maximal sequence of consecutive identical symbols. For example, in the sequence A A B B B A B, there are 4 runs: (AA), (BBB), (A), (B).

4.6 Procedure for the Run Test

  1. State H₀: the sequence of outcomes is random.
  2. Count n₁ (number of one type of outcome), n₂ (number of the other type), and R (the total number of runs observed).
  3. Too few runs suggests the data follows a pattern or trend (clustering); too many runs suggests an unusual, overly alternating pattern — both are evidence against randomness.
  4. For small samples, R is compared against critical values from Run Test tables; for larger samples, R can be converted to an approximately normal Z-statistic.

4.7 Applications of the Run Test

  • Checking whether a production process is producing defects randomly, or in a detectable, non-random pattern (a signal of a systematic problem).
  • Checking whether stock price movements (up/down) over time appear random, relevant to market efficiency testing.
  • Verifying that a sequence of survey or experimental responses was not influenced by some uncontrolled ordering effect.

3. Key Terms

Kolmogorov-Smirnov (K-S) Test
A non-parametric test checking whether sample data is consistent with a specific hypothesised distribution, using the maximum difference between empirical and theoretical cumulative distributions.
D-Statistic
The test statistic in the K-S test, the maximum absolute difference between the empirical and theoretical cumulative distribution functions.
One Sample Run Test
A non-parametric test checking whether a sequence of binary outcomes occurs in a genuinely random order.
Run
A maximal sequence of consecutive identical symbols or outcomes within a data sequence.

4. Exam-Prep Summary

  • K-S test: goodness-of-fit test comparing a sample's empirical CDF to a hypothesised theoretical CDF; D = max absolute difference between the two; reject H0 if D > critical value.
  • K-S works on ungrouped/individual data (vs Chi-Square's grouped/categorical data) — often more powerful for continuous data.
  • Run Test: checks if a binary sequence is random; Run = maximal sequence of consecutive identical symbols; too few or too many runs both indicate non-randomness.
  • Run Test applications: process defect patterns, stock price movement randomness, survey response ordering effects.

5. Practice Questions

  1. What is the Kolmogorov-Smirnov test used for? Explain its procedure.
    Show model answer
    It tests whether sample data is consistent with coming from a hypothesised distribution. The procedure compares the sample's empirical cumulative distribution function to the theoretical CDF of the hypothesised distribution, finds D (the maximum absolute difference between them), and compares D to a critical value from K-S tables; if D exceeds the critical value, H0 is rejected.
  2. Differentiate between the Kolmogorov-Smirnov test and the Chi-Square goodness-of-fit test.
    Show model answer
    The K-S test works directly with individual, ungrouped data values by comparing cumulative distributions, while the Chi-Square test works with data grouped into categories or class intervals. The K-S test is often considered more powerful for continuous data since it avoids the information loss from grouping.
  3. What is a 'run' in the context of the One Sample Run Test? What does the test check for?
    Show model answer
    A run is a maximal sequence of consecutive identical symbols or outcomes in a data sequence. The One Sample Run Test checks whether a sequence of binary outcomes occurs in a genuinely random order; too few runs suggest clustering/patterning, and too many runs suggest unusual over-alternation, both indicating the sequence is not random.
  4. State two applications of the One Sample Run Test.
    Show model answer
    Checking whether a production process generates defects randomly or in a detectable non-random pattern, and checking whether stock price movements over time appear random, which is relevant to testing market efficiency.
