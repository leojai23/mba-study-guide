Unit 4Introduction to Non-Parametric Tests and the Sign Test

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

Unit 3's tests all assumed the population data followed a known distribution (usually normal). This unit covers non-parametric tests, which make far fewer assumptions. This opening topic introduces the sign test, one of the simplest non-parametric tests.

2. Detailed Notes

1.1 What Are Non-Parametric Tests?

Non-parametric tests are hypothesis tests that do not require the population to follow a specific distribution (such as normal), and often work directly with the ranks or signs of data rather than the raw numerical values themselves.

1.2 When to Use Non-Parametric Tests

  • When the population distribution is unknown or clearly not normal.
  • When the sample size is very small, making it hard to verify normality.
  • When the data is ordinal (ranked) rather than truly numerical/interval-scaled.
  • When the data contains outliers that would distort a parametric test like the t-test.

1.3 Non-Parametric vs Parametric Tests

1.4 The Sign Test — Single Sample

The single-sample sign test checks whether a population median equals a hypothesised value, using only the sign (+ or −) of each observation's deviation from that hypothesised median, ignoring the actual magnitude of the deviation.

Procedure

  1. State H₀: population median = a specified value.
  2. For each observation, record a "+" if it is above the hypothesised median, a "−" if below, and discard any observation exactly equal to it.
  3. Count the number of plus signs and minus signs.
  4. Under H₀, the number of plus signs follows a Binomial distribution with p = 0.5; this Binomial (or its normal approximation for larger n) is used to test whether the observed split is consistent with chance.

1.5 The Sign Test — Paired Data

The paired sign test is the non-parametric counterpart to the paired t-test from Unit 3, used to compare two related/matched samples (e.g. "before" and "after" scores) without assuming the differences are normally distributed.

Procedure

  1. For each pair, calculate the difference and record only its sign (+ if the second value is greater, − if smaller, discard ties).
  2. Test whether the resulting mix of plus and minus signs is consistent with there being no systematic difference between the paired conditions (H₀: equal numbers of + and − signs are equally likely, i.e. p = 0.5).

1.6 Advantages and Limitations of the Sign Test

  • Advantage: Extremely simple to apply and requires no distributional assumptions.
  • Limitation: Because it discards the magnitude of each difference and uses only its sign, it is less statistically powerful than tests (parametric or non-parametric) that use more information from the data.

3. Key Terms

Non-Parametric Test
A hypothesis test that does not require the population to follow a specific distribution, often working with ranks or signs rather than raw values.
Sign Test
A non-parametric test that uses only the sign (+ or -) of each observation's deviation from a hypothesised value, ignoring magnitude.
Paired Sign Test
A non-parametric test comparing two related samples using only the sign of the difference within each matched pair.

4. Exam-Prep Summary

  • Non-parametric tests make no/few distributional assumptions; used for unknown/non-normal distributions, ordinal data, small samples, or outlier-prone data.
  • Parametric (Z/t/F/ANOVA) vs Non-parametric (Sign, Mann-Whitney, Kruskal-Wallis, Chi-Square): distributional assumptions vs none; generally more power vs more robustness.
  • Single-sample sign test: counts +/- signs of deviations from hypothesised median; under H0, number of + signs ~ Binomial(n, 0.5).
  • Paired sign test: non-parametric counterpart to paired t-test, uses sign of each pair's difference only.
  • Sign test advantage: simple, few assumptions; limitation: ignores magnitude, so less powerful than tests using full data.

5. Practice Questions

  1. When are non-parametric tests preferred over parametric tests?
    Show model answer
    Non-parametric tests are preferred when the population distribution is unknown or clearly not normal, when sample sizes are too small to verify normality, when data is ordinal rather than truly numerical, or when outliers would distort a parametric test.
  2. Explain the procedure of the single-sample sign test.
    Show model answer
    State H0 that the population median equals a specified value; record a plus sign for each observation above that value and a minus sign for each below (discarding ties); count the pluses and minuses; since the number of plus signs follows a Binomial(n, 0.5) distribution under H0, test whether the observed split is consistent with this.
  3. What is the paired sign test used for?
    Show model answer
    It is the non-parametric counterpart to the paired t-test, used to compare two related/matched samples (such as before-and-after scores) by looking only at the sign of the difference within each pair, without assuming the differences are normally distributed.
  4. State an advantage and a limitation of the sign test.
    Show model answer
    Advantage: it is extremely simple to apply and requires no distributional assumptions. Limitation: because it discards the magnitude of each difference and uses only its sign, it is less statistically powerful than tests that use more information from the data.
