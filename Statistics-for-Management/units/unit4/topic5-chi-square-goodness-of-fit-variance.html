Unit 4Chi-Square Test for Goodness of Fit and Single Sample Standard Deviation

Book: Statistics for Management (BA4101, Anna University MBA Sem I, Regulation 2021)

1. Overview

The Chi-Square distribution underlies several important non-parametric tests. This topic covers two of them: testing whether observed data fits an expected distribution (goodness of fit), and testing a claimed value for a single population's variance or standard deviation.

2. Detailed Notes

5.1 Chi-Square Test for Goodness of Fit — Purpose

The Chi-Square Goodness of Fit Test checks whether observed categorical data matches an expected (hypothesised) distribution across several categories.

5.2 Hypotheses

H₀: The observed frequencies match the expected (hypothesised) frequencies.
H₁: The observed frequencies do not match the expected frequencies.

5.3 The Chi-Square Statistic

χ² = Σ [(Oi − Ei)² ÷ Ei]

where Oi is the observed frequency in category i, and Ei is the expected frequency in category i under H₀, summed across all categories.

Degrees of freedom: df = (number of categories) − 1.

5.4 Decision Rule

The calculated χ² is compared against the critical χ² value for the chosen significance level and df. If calculated χ² exceeds the critical value, H₀ is rejected — the observed data does not fit the hypothesised distribution well.

5.5 Conditions for Using the Chi-Square Test

  • Data must be in the form of frequencies (counts), not percentages or raw scores.
  • Observations should be independent of one another.
  • Expected frequencies in each category should generally be 5 or more for the approximation to be reliable; categories may need to be combined if this is not met.

5.6 Chi-Square Test for a Single Sample's Standard Deviation (Variance)

This test checks whether a population's variance (or standard deviation) equals a specific claimed value, using a sample.

H₀: σ² = σ₀² (the population variance equals the claimed value)

χ² = [(n − 1) × s²] ÷ σ₀²

where n is the sample size, s² is the sample variance, and σ₀² is the claimed population variance under H₀, with df = n − 1.

Decision Rule

This test can be one-tailed or two-tailed depending on H₁. The calculated χ² is compared against the appropriate critical χ² value(s) from χ² tables with df = n − 1, and H₀ is rejected if the calculated value falls in the rejection region.

3. Key Terms

Chi-Square Goodness of Fit Test
A test checking whether observed categorical frequencies match an expected (hypothesised) distribution, using the Chi-Square statistic.
Chi-Square Statistic
The test statistic Sum of [(Observed - Expected)^2 / Expected] across categories, used in several Chi-Square-based tests.
Chi-Square Test for Variance
A test checking whether a population's variance equals a claimed value, using (n-1)s^2 / sigma0^2 as the test statistic.

4. Exam-Prep Summary

  • Chi-Square Goodness of Fit: chi^2 = Sum[(Oi - Ei)^2 / Ei], df = (number of categories) - 1.
  • Conditions: data as frequencies/counts, independent observations, expected frequency >= 5 per category (combine categories if not).
  • Chi-Square test for variance: chi^2 = (n-1)s^2 / sigma0^2, df = n-1, tests H0: sigma^2 = sigma0^2.
  • Reject H0 if calculated chi^2 exceeds the critical chi^2 value at the chosen df and significance level.

5. Practice Questions

  1. State the formula for the Chi-Square Goodness of Fit test and its degrees of freedom.
    Show model answer
    chi^2 = Sum of [(Oi - Ei)^2 / Ei], where Oi and Ei are the observed and expected frequencies in category i. Degrees of freedom = (number of categories) - 1.
  2. State the conditions required for using the Chi-Square test.
    Show model answer
    Data must be in the form of frequencies (counts), observations must be independent, and expected frequencies in each category should generally be 5 or more, with categories combined if this condition is not met.
  3. State the formula used to test a population variance using the Chi-Square distribution.
    Show model answer
    chi^2 = [(n-1) x s^2] / sigma0^2, where n is the sample size, s^2 is the sample variance, and sigma0^2 is the claimed population variance under H0, with degrees of freedom df = n - 1.
