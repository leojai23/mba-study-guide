Unit 4Multivariate Analysis

Book: Business Research Methods (BA4205, Anna University MBA Sem II, Regulation 2021)

1. Overview

When a research problem involves many variables at once, multivariate techniques are needed. This topic surveys the major multivariate methods used in business research and what each is designed to achieve.

2. Detailed Notes

5.1 Introduction to Multivariate Analysis

Multivariate analysis refers to statistical techniques that analyse relationships among three or more variables simultaneously, used when a business problem is too complex to be understood through univariate or bivariate methods alone.

5.2 Multivariate Statistical Techniques: Overview

TechniqueObjective
Multiple Regression and CorrelationPredicts a single dependent variable from two or more independent variables; multiple correlation measures the overall strength of that combined relationship.
Discriminant AnalysisClassifies observations into two or more pre-defined categories based on a set of predictor variables.
Factor AnalysisReduces a large number of correlated variables into a smaller number of underlying "factors".
Cluster AnalysisGroups observations into clusters so that items within a cluster are similar and items in different clusters are dissimilar.
Multi-Dimensional Scaling (MDS)Represents the perceived similarity or dissimilarity among objects visually in a low-dimensional space (a "perceptual map").
Conjoint AnalysisDetermines the relative importance consumers place on different attributes of a product or service.

5.3 Multiple Regression and Correlation

Multiple regression extends simple regression to two or more independent variables: Y = a + b₁X₁ + b₂X₂ + ... + bₘXₘ. Multiple correlation (R) measures how well the full set of independent variables together predicts the dependent variable.

5.4 Discriminant Analysis

Objectives: to identify which predictor variables best distinguish between groups, and to classify new observations into the correct group.
Steps: define the groups, select predictor variables, estimate the discriminant function, and validate its classification accuracy.
Applications: classifying customers as likely to churn or not, or classifying loan applicants as high or low credit risk.

5.5 Factor Analysis

Objectives: to simplify a large set of correlated variables (e.g. many survey items) into a smaller number of meaningful underlying dimensions.
Steps: compute the correlation matrix, extract factors, rotate factors for interpretability, and name/interpret the resulting factors.
Applications: identifying the underlying dimensions of customer satisfaction from a long list of survey questions.

5.6 Cluster Analysis

Objectives: to segment a set of observations into naturally occurring, homogeneous groups.
Steps: choose a similarity/distance measure, select a clustering method, decide the number of clusters, and profile each cluster.
Applications: market segmentation based on customer behaviour or demographics.

5.7 Multi-Dimensional Scaling (MDS)

Objectives: to visually map how objects (e.g. competing brands) are perceived relative to one another.
Procedure: collect similarity/preference data, apply the MDS algorithm to position objects in a low-dimensional space, and interpret the resulting map.
Applications: competitive brand-positioning maps.

5.8 Conjoint Analysis

Objectives: to measure how much each attribute of a product (e.g. price, brand, features) contributes to overall consumer preference.
Procedure: select attributes to be tested, present respondents with combinations of attributes to rank or rate, and estimate each attribute's relative importance ("utility").
Applications: new-product design and pricing decisions.

3. Key Terms

Multivariate Analysis
Statistical techniques that analyse relationships among three or more variables simultaneously.
Multiple Regression
Regression analysis that predicts a dependent variable from two or more independent variables.
Discriminant Analysis
A technique that classifies observations into pre-defined categories based on predictor variables.
Factor Analysis
A technique that reduces a large number of correlated variables into a smaller number of underlying factors.
Cluster Analysis
A technique that groups observations into clusters of similar items.
Conjoint Analysis
A technique that measures the relative importance consumers place on different product attributes.

4. Exam-Prep Summary

  • Multivariate techniques: multiple regression, discriminant analysis, factor analysis, cluster analysis, MDS, conjoint analysis.
  • Multiple regression: Y = a + b1X1 + b2X2 + ... + bnXn; multiple correlation R = overall predictive strength.
  • Discriminant analysis = classifies observations into pre-defined groups.
  • Factor analysis = reduces many variables into fewer underlying factors.
  • Cluster analysis = groups observations into similar segments (no pre-defined groups).
  • Conjoint analysis = measures relative importance of product attributes to preference.

5. Practice Questions

  1. What is multivariate analysis and when is it used?
    Show model answer
    Multivariate analysis refers to statistical techniques that analyse relationships among three or more variables simultaneously. It is used when a business problem is too complex to be understood through examining one variable (univariate) or two variables (bivariate) at a time.
  2. Differentiate between factor analysis and cluster analysis.
    Show model answer
    Factor analysis reduces a large number of correlated variables into a smaller number of underlying factors, simplifying the variable set itself. Cluster analysis instead groups observations (such as customers) into homogeneous segments based on similarity across variables, without reducing the variables themselves.
  3. Explain discriminant analysis with its objectives and an application.
    Show model answer
    Discriminant analysis identifies which predictor variables best distinguish between pre-defined groups and classifies new observations into the correct group. A common application is classifying loan applicants as high or low credit risk based on variables such as income, credit history and debt level.
  4. What is conjoint analysis used for in business research?
    Show model answer
    Conjoint analysis measures how much each attribute of a product or service, such as price, brand and features, contributes to overall consumer preference, by having respondents evaluate combinations of attributes. It is commonly applied in new-product design and pricing decisions.
