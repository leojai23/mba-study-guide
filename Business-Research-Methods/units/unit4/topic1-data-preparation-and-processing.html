Unit 4Data Preparation and Processing

Book: Business Research Methods (BA4205, Anna University MBA Sem II, Regulation 2021)

1. Overview

Raw data collected from the field is rarely ready for analysis. This topic covers the full sequence of operations — validation, editing, coding, classification, data entry and tabulation — that turn raw responses into analysis-ready data.

2. Detailed Notes

1.1 Introduction and Significance

Data preparation and processing is the set of steps that convert raw, collected data into a clean, organised and structured form suitable for analysis. Skipping or rushing this stage risks introducing errors that undermine every conclusion drawn later.

1.2 Operations in Data Preparation

The typical sequence is: validation → editing → coding → classification → data entry → tabulation.

1.3 Validation

Validation checks that each completed questionnaire/response was gathered honestly, from a qualified respondent, under proper conditions, and is complete enough to be usable.

1.4 Editing

Essentials of Editing

Editing reviews completed data for accuracy, consistency, completeness and uniformity before coding begins.

Stages of Editing

  • Field editing — a quick check done by the interviewer/investigator shortly after collection, while memory is fresh.
  • Central/office editing — a thorough, uniform review conducted later by trained editors at a central location.

Handling Unsatisfactory Responses

Options include contacting the respondent again, returning the questionnaire to the field for completion, inferring the missing answer from other responses, discarding the response, or treating it as missing data in analysis.

1.5 Coding

Principles of Coding

Coding assigns a numerical or symbolic value to each possible response so it can be processed statistically; codes should be exhaustive (cover every possible answer), mutually exclusive, and consistently applied.

Procedure

Develop a coding scheme/codebook from the questionnaire and a sample of responses, apply it consistently across all responses, and spot-check for coder errors.

1.6 Classification

Principles

Classification groups data into categories that are relevant to the research objectives, exhaustive and mutually exclusive.

Types

  • Qualitative classification — by attribute or quality (e.g. gender, occupation).
  • Quantitative classification — by numerical magnitude (e.g. income bands, age groups).
  • Geographical classification — by location.
  • Chronological classification — by time period.

1.7 Data Entry

Coded data is entered into a spreadsheet or statistical software package (e.g. SPSS, Excel) for processing, with validation checks to catch entry errors.

1.8 Tabulation

Characteristics of a Good Table

Clear title, properly labelled rows/columns, source noted, and footnotes for any necessary clarification.

Types of Tabulation

  • Simple tabulation — one variable at a time.
  • Cross tabulation — two or more variables shown together.

Rules of Tabulation

Keep tables simple and focused, use consistent units, round figures appropriately, and ensure totals are correctly shown.

3. Key Terms

Editing
The review of completed data for accuracy, consistency, completeness and uniformity before coding.
Coding
The process of assigning a numerical or symbolic value to each possible response so it can be processed statistically.
Classification
The grouping of data into categories that are relevant, exhaustive and mutually exclusive.
Tabulation
The systematic arrangement of classified data into rows and columns for easy reference and analysis.

4. Exam-Prep Summary

  • Data preparation sequence: validation → editing → coding → classification → data entry → tabulation.
  • Editing stages: field editing (by interviewer, immediate) vs central editing (by trained editors, thorough).
  • Coding rules: codes must be exhaustive and mutually exclusive.
  • Classification types: qualitative, quantitative, geographical, chronological.
  • Tabulation types: simple (one variable) vs cross tabulation (two or more variables).

5. Practice Questions

  1. Describe the sequence of operations in data preparation.
    Show model answer
    Data preparation typically follows a sequence of validation (checking the data was genuinely and properly collected), editing (reviewing for accuracy and completeness), coding (assigning numerical values to responses), classification (grouping into relevant categories), data entry (into software), and tabulation (arranging into summary tables).
  2. Differentiate between field editing and central editing.
    Show model answer
    Field editing is a quick check performed by the interviewer or investigator shortly after data collection, while memory of the interaction is still fresh. Central (office) editing is a more thorough, uniform review carried out later by trained editors at a central location, applying consistent standards across all collected data.
  3. What principles must be followed in coding and classification?
    Show model answer
    Coding requires that codes assigned to responses be exhaustive, covering every possible answer, and mutually exclusive, with no overlap, and applied consistently across all responses. Classification follows similar principles, grouping data into categories that are relevant to the research objectives, exhaustive, and mutually exclusive.
