Unit 4Hypothesis Testing

Book: Business Research Methods (BA4205, Anna University MBA Sem II, Regulation 2021)

1. Overview

The closing topic of this unit covers hypothesis testing — the formal statistical procedure for deciding, based on sample data, whether to accept or reject a hypothesis about a population.

2. Detailed Notes

6.1 Introduction to Hypothesis Testing

Hypothesis testing is a statistical procedure that uses sample data to evaluate whether there is enough evidence to reject a stated hypothesis about a population, allowing researchers to make inferential decisions with a known level of risk.

6.3 Elements of Hypothesis Testing

  • Null hypothesis (H₀) and alternative hypothesis (H₁).
  • Test statistic appropriate to the data and hypothesis.
  • Level of significance (α).
  • Decision rule (critical value or p-value approach).

6.4 Steps in Testing a Hypothesis

  1. State the null and alternative hypotheses.
  2. Choose the level of significance (α).
  3. Select the appropriate test statistic.
  4. Determine the critical value/region or compute the p-value.
  5. Calculate the test statistic from the sample data.
  6. Compare the calculated value with the critical value (or p-value with α) and decide whether to reject H₀.
  7. State the conclusion in the context of the original business problem.

6.5 Importance and Limitations of the Tests of Hypothesis

Hypothesis tests provide an objective, standardised way to decide whether an observed sample result reflects a real population effect or could plausibly be due to chance, which is essential for evidence-based decision-making. Their limitations include the risk of Type I/Type II errors, sensitivity to sample size, and the fact that statistical significance does not automatically imply practical/managerial significance.

6.6 Important Terms in Hypothesis Testing

Errors in Hypothesis Testing

  • Type I Error (α) — rejecting a true null hypothesis (a "false positive").
  • Type II Error (β) — failing to reject a false null hypothesis (a "false negative").

Level of Significance

The probability of committing a Type I error that the researcher is willing to accept, commonly set at 0.05 (5%) or 0.01 (1%).

Degree of Freedom

The number of independent values that are free to vary in a calculation, used to identify the correct reference distribution (e.g. for the t-test or chi-square test).

One-Tailed and Two-Tailed Tests

A one-tailed test places the entire rejection region in one direction (used when the hypothesis specifies a direction, e.g. "greater than"). A two-tailed test splits the rejection region between both ends (used when the hypothesis only states "different from", with no specified direction).

Measuring the Power of a Hypothesis Test

The power of a test is the probability of correctly rejecting a false null hypothesis, equal to (1 − β). Higher power means a greater ability to detect a real effect when one exists; power increases with larger sample sizes.

3. Key Terms

Null Hypothesis (H0)
A hypothesis stating there is no effect or difference, which hypothesis testing seeks to reject or fail to reject.
Type I Error
Rejecting a null hypothesis that is actually true (a false positive), with probability alpha.
Type II Error
Failing to reject a null hypothesis that is actually false (a false negative), with probability beta.
Level of Significance
The probability of committing a Type I error that the researcher is willing to accept, commonly 0.05 or 0.01.
Power of a Test
The probability of correctly rejecting a false null hypothesis, equal to 1 minus beta.

4. Exam-Prep Summary

  • Steps: state H0/H1 → choose alpha → select test statistic → find critical value/p-value → compute statistic → decide → conclude.
  • Type I error (alpha) = reject true H0; Type II error (beta) = fail to reject false H0.
  • Level of significance = acceptable probability of Type I error (commonly 0.05 or 0.01).
  • One-tailed test = directional hypothesis; Two-tailed test = non-directional hypothesis.
  • Power of test = 1 - beta = probability of correctly rejecting a false H0; increases with sample size.

5. Practice Questions

  1. Explain Type I and Type II errors in hypothesis testing.
    Show model answer
    A Type I error occurs when a true null hypothesis is incorrectly rejected (a false positive), with probability denoted alpha. A Type II error occurs when a false null hypothesis is incorrectly not rejected (a false negative), with probability denoted beta. There is generally a trade-off between the two: reducing one tends to increase the other for a fixed sample size.
  2. Outline the steps involved in testing a hypothesis.
    Show model answer
    Hypothesis testing proceeds by stating the null and alternative hypotheses, choosing the level of significance, selecting the appropriate test statistic, determining the critical value or p-value, calculating the test statistic from sample data, comparing it against the critical value or p-value to decide whether to reject the null hypothesis, and finally stating the conclusion in the context of the business problem.
  3. Differentiate between one-tailed and two-tailed tests.
    Show model answer
    A one-tailed test places the entire rejection region in one direction and is used when the alternative hypothesis specifies a direction, such as 'greater than'. A two-tailed test splits the rejection region between both ends of the distribution and is used when the alternative hypothesis simply states that a difference exists, without specifying its direction.
  4. What is meant by the power of a hypothesis test?
    Show model answer
    The power of a hypothesis test is the probability of correctly rejecting a null hypothesis that is actually false, calculated as 1 minus beta (the Type II error probability). Higher power means a greater ability to detect a real effect, and power generally increases as the sample size increases.
